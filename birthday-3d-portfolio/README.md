# A Little Universe — 3D-inspired Birthday Portfolio

A mobile-first birthday microsite made with HTML, CSS and vanilla JavaScript. It uses the uploaded photos, layered portrait framing, orbit effects, subtle parallax, a tappable photo lightbox, and an interactive birthday cake.

## Run locally

1. Download and unzip this project.
2. Open the `birthday-3d-portfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension (or use any local static web server).
4. Right-click `index.html` → **Open with Live Server**.
5. Test it with your browser's mobile device preview (Ctrl+Shift+M in Chrome).

You can also open `index.html` directly, but a local server is recommended.

## Personalise it

- Replace the placeholder wording in `index.html` with her name, birthday date, and your own message.
- Replace `assets/portrait-main.jpeg` to change the large hero portrait.
- Replace `assets/photo-1.jpeg`, `photo-2.jpeg`, and `photo-3.jpeg` to change the gallery images. Keep the same filenames, or update the paths in `index.html`.
- Change the colours near the top of `style.css` in the `:root` section.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `birthday-universe`.
2. Upload the contents of this folder (make sure `index.html` is at the repository root, not inside another nested folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/birthday-universe/`.

No API keys, build tools, or paid hosting are required. The Google Fonts import needs an internet connection; the rest of the site is static.
